
# Doce Encanto Café

## Sobre o projeto

A Doce Encanto Café é uma loja fictícia de cafés e sobremesas. O projeto foi desenvolvido para a atividade de simulação de compras.

## Produtos e preços

- Café Cremoso: R$ 8,00
- Brownie: R$ 10,00
- Bolo de Morango: R$ 12,00
- Cappuccino: R$ 14,00

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Localize o arquivo index.html.
3. Abra o arquivo no navegador.

## Como funciona

O usuário clica no botão Simular compra e informa a quantidade desejada de cada produto.

O programa calcula os valores, apresenta os subtotais e mostra o total da compra.

A loja utiliza uma regra de desconto de 10% para compras a partir de R$ 50,00.
